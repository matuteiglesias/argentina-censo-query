# argentina-censo-query

Semantic query compiler for Argentina's 2022 Census.

The product interprets a statistical question, makes the interpretation explicit, and compiles one canonical `CensusQuery` into copyable SQL, Redatam Process, and INDEC Redatam WebServer instructions.

**It does not execute queries or return Census results.**

Development starts from contract-first phases A0–A2 and B0.
